# Завершення терміну петицій

Статус expired («Термін дії минув») застосовується лише до active, коли deadline <= timezone.now(). Петиція залишається публічною, голоси зберігаються. Стани in_review, answered та інші не змінюються.

Статус hidden видалено. Міграція 0006 переводить старі приховані петиції на moderation для повторної перевірки адміністратором. Вони залишаються непублічними; текст, голоси та причина приховування зберігаються. Відкат міграції не відновлює статус hidden у цих записах.

API списків, окремої петиції, профілю, статистики й Django Admin оновлює прострочені записи перед читанням. Голосування перевіряє дедлайн під блокуванням рядка у транзакції. Спроба голосування після завершення повертає HTTP 409 із detail «Термін збору голосів завершено.».

Застосування зміни схеми у середовищі з налаштованими Django і MySQL:

    python manage.py migrate

Для збереження статусів без запитів користувачів запускайте раз на хвилину:

    python manage.py expire_petitions

Команда придатна для повторного запуску. Вона змінює лише статус і status_changed_at прострочених активних петицій.

У Windows Task Scheduler створіть завдання з повторенням щохвилини: програма — повний шлях до .venv/Scripts/python.exe, аргументи — manage.py expire_petitions, робочий каталог — корінь проєкту. Середовище облікового запису завдання має містити ті самі DJANGO_SECRET_KEY, DJANGO_DEBUG та MYSQL_* змінні, що використовує backend. Змінні export із вікна Git Bash планувальник не успадковує. На Linux аналогічну команду можна запускати через cron із налаштованим середовищем.

Планувальник потрібно налаштувати окремо на машині запуску. Без нього статус оновлюється під час наступного серверного запиту; голосування після дедлайну все одно блокується.

# Видалення категорій

Vue використовує наявний DELETE /api/categories/{id}/ із sessions і CSRF. Адміністратор підтверджує видалення, після HTTP 204 категорія зникає зі списку без перезавантаження сторінки. HTTP 409 означає, що категорія використовується петиціями; HTTP 403 — відсутність прав або CSRF; HTTP 404 — категорію не знайдено. Зв'язок Petition.category залишається PROTECT.
